# Getting help / Cómo obtener ayuda

| I want to… / Quiero… | Go to / Vaya a |
|---|---|
| Ask how to do something · Preguntar cómo hacer algo | [Discussions → Q&A](https://github.com/nunez1822/ICCWorship/discussions) |
| Report something that is broken · Reportar algo que falla | [New issue → Bug report](https://github.com/nunez1822/ICCWorship/issues/new/choose) |
| Suggest a feature · Sugerir una función | [New issue → Feature request](https://github.com/nunez1822/ICCWorship/issues/new/choose) |
| Report a security problem · Reportar un problema de seguridad | **Privately / en privado:** [Security → Report a vulnerability](https://github.com/nunez1822/ICCWorship/security/advisories/new). See [SECURITY.md](SECURITY.md) |
| Report a Code of Conduct problem · Reportar un problema de conducta | **Privately / en privado:** email / correo <kevin.nunez@convitutor.com>. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## Before you report a bug / Antes de reportar un error
- **Version / versión:** Settings → About · Ajustes → Acerca de.
- **Your data folder / su carpeta de datos:** Settings → Backup → 📂 Open data folder · Ajustes → Copia de seguridad → 📂 Abrir carpeta de datos.
- **Don't post private information / no publique información privada:** issues are public. Leave out names,
  phone numbers and prayer requests · los reportes son públicos; no incluya nombres, teléfonos ni peticiones de oración.

ICCWorship is maintained by volunteers. We answer as soon as we can.
ICCWorship lo mantienen voluntarios. Respondemos lo antes posible.
